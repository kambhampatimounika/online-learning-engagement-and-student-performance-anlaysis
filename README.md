# 📊 Student Retention & Online Education Analysis – Power BI

## 📌 Project Overview

This project analyzes online education data using **Microsoft Power BI** to understand student engagement, academic performance, and retention patterns.

## 🎯 Objectives

* Analyze student activity and engagement.
* Study academic performance.
* Identify retention patterns.
* Create interactive Power BI dashboards.
* Present key insights through visualizations.

## 🗂️ Dataset

The dataset contains student information such as **gender, education, region, engagement, clicks, scores, final results, performance level, and risk level**.

## 🧹 Data Preparation

Data was cleaned using **Power Query** by:

* Removing duplicates.
* Handling missing values.
* Standardizing data.
* Checking data types.

## 📊 Dashboard

The dashboard analyzes:

* Student demographics
* Engagement and activity
* Academic performance
* Final results
* Risk and retention

## 🔍 Key Insights

The dashboard helps identify **engagement patterns, performance differences, student risk levels, and retention-related trends**.

## 🛠️ Tools

**Power BI | Power Query | DAX | CSV | GitHub**

## 🚀 Future Scope

Future improvements include **predictive dropout analysis, time-based analysis, additional visuals, and regularly updated data**.

## ✅ Conclusion

This project demonstrates how Power BI can transform student education data into **interactive and useful insights for understanding engagement, performance, and retention**.
